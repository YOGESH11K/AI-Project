# AI Project

Collection of small AI / Python projects made during school.

## Folders

- **class6**
  - **CaloryCalculator** - A Streamlit web app that estimates daily calorie need from name, age, weight and height.
  - **NumberGuessingGame** - A Streamlit web app where you guess a secret number between 1 and 10 within 3 chances.

## Run locally

```bash
streamlit run class6/CaloryCalculator/app.py
streamlit run class6/NumberGuessingGame/app.py
```
